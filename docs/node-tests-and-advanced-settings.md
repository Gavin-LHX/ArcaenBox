# 节点测试与高级设置

点击节点卡片右侧的“⋮”，直接对该节点执行 TCP 延迟、真连接延迟、UDP 延迟或下载测速。长按节点卡片进入多选，在主列表中勾选后从顶部操作栏开始批量测试，也可以全选/清空。测试前不再弹出另一份节点选择列表。长按卡片的“⋮”可拖动排序。

结果显示在节点下方，分别记录，不互相覆盖；点击结果可查看时间和失败原因。真连接测试决定节点的连接状态，单独的 TCP/UDP 失败不会覆盖已经通过的真连接结果。菜单中的“按测试结果排序”可分别选择四种结果。

- TCP 延迟：直连节点的服务器端口，衡量 TCP 握手时间。它不能证明代理认证、UDP 或网站访问可用。纯 UDP 协议（例如 Mieru UDP）显示“不支持此项测试”，不会因此把节点标为不可用。
- 真连接延迟：通过所选节点访问设置中的测试 URL，只有成功的 HTTP 响应才算通过。
- UDP 延迟：通过所选节点发送 NTP、DNS、STUN 或 Minecraft Bedrock 请求，并校验响应与请求对应。可选预设，也可输入 `协议:主机:端口`；IPv6 地址使用方括号。旧的无协议前缀地址仍按 NTP 处理。目标服务器或网络限制可能导致某种探测失败，不能因此认定所有 UDP 都不可用。
- 下载速度：通过所选节点下载设置中的 HTTPS 文件。按节点依次测试，避免并行下载互相争抢带宽。默认每个节点最多 20 MiB、10 秒，可在设置中修改。点击菜单立即测试，进度窗口可随时取消。显示的是实际读取字节的平均 MiB/s，包含建立连接所用时间。

延迟测试并发数、单节点超时、真连接 URL、UDP 地址、下载地址/流量上限和出口 IP 服务均提供预设及固定可见的“自定义”按钮。取消后会关闭该次测试的连接和内核，保留已完成的结果；未勾选节点不受影响。测试使用独立入口，用户路由不会把测试请求分配给其他节点。

底栏显示连接状态、当前节点的真连接延迟、代理出口公网 IP 和上下行速度。IP 服务返回国家代码时一并显示。点击底栏重新检测；切换节点或断开后清除旧结果。检测失败不会回退直连来显示本机出口。

VPN 已连接时也可以测试其他节点，不需要先断开。测试内核的外部连接通过 VPN 服务保护，避免再次经过当前节点；系统拒绝保护时该次测试会显示错误。

## 路由与资源

路由页顶部提供自定义、绕过大陆（白名单）、代理列表内域名（黑名单）、全局代理四种预设。切换预设会保留已有自定义规则。白名单以代理为默认出口，黑名单以直连为默认出口；返回自定义后可继续编辑规则。

路由菜单支持从文件、剪贴板、HTTPS URL 导入，导入前可预览并取消。支持 ArcaenBox 导出的 JSON 和常见 sing-box/Xray 路由字段。导入会追加到已有自定义规则并切换到自定义模式。存在不支持的字段、无效端口或无法唯一匹配的节点名称时，整次导入失败，原有规则不变。

桌面进程名（如 `game.exe`）需要在 Android 上重新选择应用包。JSON 中的节点出口名称必须与本机已有节点名称唯一匹配。导出使用节点名称而不是本地数据库编号，便于迁移。远程 URL 导入是一次性操作。资源文件的导入、更新和删除位于侧栏“资源文件”。

## sing-box 设置

高级 DNS 提供 Bootstrap IP、缓存开关/容量/超时、乐观缓存、自定义 Hosts、Android 系统 Hosts，以及 AAAA、SVCB/HTTPS 查询控制。Hosts 格式为每行 `域名 IP [IP…]`。屏蔽查询返回空的成功响应。

自定义 DNS 可以分别配置 VPN 和仅代理模式的 JSON。启用后会替代基础/高级 DNS 配置；必须保留 `dns-direct` 和 `dns-remote` 标签，以供节点解析及路由使用。“导入默认 DNS”仅填充空模板。完整自定义配置节点仍使用自身的 DNS。

还可以设置嗅探协议、默认 TLS 指纹、规则集/FakeIP 缓存和第二混合监听端口。指纹默认值不会覆盖节点中显式设置的指纹。第二端口支持用户名和密码认证；填写认证信息后，原始端口仅供本机访问，以保留应用内部更新和 Android HTTP 代理的连接能力。监听端口修改需要重新连接。

Windows 系统代理/PAC、托盘、桌面进程规则和 Xray 专用选项没有 Android/sing-box 等价项。现有完整自定义配置入口用于高级配置；它与普通节点设置的作用范围不同。
