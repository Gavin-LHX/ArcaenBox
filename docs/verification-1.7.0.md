## 修复对照

2026-10-01 在本地 Android 15 模拟器安装旧候选版本 `3a83377`，按 APK 哈希确认身份。路由开关的连续点击、拖动后点击存在丢失；新增回归可以稳定检出。原因是子开关阻止父级拦截后，ItemTouchHelper 的长按检测未收到后续抬手，错误进入规则排序状态。新版在列表接收按下事件时识别开关区域，令整段开关手势不参与排序或滑删，保留卡片自身的长按排序。

旧候选版的操作按钮在获得键盘焦点后，边框像素变化为 0。新版在玻璃表面上方绘制焦点边框，并修复完整玻璃层的透明度合成。

[最终构建 36889509547](https://github.com/Gavin-LHX/ArcaenBox/actions/runs/36889509547)完成 APK 构建、签名验证和 63 项单元测试，但作业整体因云端模拟器消失而失败。启动、配置导入与服务启停已通过；玻璃动效、浅色/深色、大字体阶段留下截图。在设置降低透明度之前，ADB 返回 `device 'emulator-5554' not found`，随后模拟器控制端口 5554 也拒绝连接。保存的日志没有模拟器退出码、OOM 或致命崩溃栈，不能确认具体原因，也不将该次云端运行算作完整通过。

## 验证范围

本轮使用 Android 15 模拟器。2026-10-01 至 10-02 的设备枚举未发现 Pixel，因此本轮没有 Pixel 真机通过结论。VPN 测试使用隔离的本地 SOCKS 配置，检查前台服务、TUN 生命周期及样式切换时的进程和接口身份；不代表用户外部节点的网络性能。API 31–32 的模糊降级及 API 30 以下的兼容表面未在本轮分别实机运行。

这是 Android 上的 Liquid Glass 风格实现，并非 Apple 系统组件；不宣称与 iOS 的私有渲染、容器融合及全部系统转场完全一致。
