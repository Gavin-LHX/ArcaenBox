# 连接与资源管理

ArcaenBox 1.6.0 在侧栏提供「资源文件」和「内核管理」。应用包名与签名沿用 1.5.0，保留原有节点与设置。

## VPN 授权

Android 同一用户只能使用一个 VPN。如果 NekoBox 等其他应用启用了「始终开启 VPN」，系统会直接结束另一款应用的授权页。请先在系统 VPN 设置中关闭其他应用的始终开启选项，返回 ArcaenBox 点击连接。部分手机还有独立的「创建 VPN 连接」权限，也需要允许 ArcaenBox。

授权失败时，应用提供系统 VPN 设置与应用权限入口。不会自动修改其他应用的设置，也不会把系统拒绝创建接口误报为需要重启手机。

## 出口 IP

连接后底部显示通过当前代理查询到的出口公网 IP。查询使用仅监听本机的独立 SOCKS 入口，优先路由到当前代理，避免被直连规则改变查询路径。点击底部可同时重试 IP 查询与延迟测试。断开连接、切换节点会取消旧查询；失败显示失败状态，不回退直连。

启动独立内核时，IP 查询会对短暂的连接失败自动重试，等待内核开始监听。未连接时保留底栏和连接按钮，避免连接按钮跟随底栏移出屏幕。

设置中的「出口 IP 查询地址」接受返回纯文本 IP 或 `{"ip":"..."}` 的 HTTPS 服务。完整自定义配置需明确指定代理出口（`route.final` 或 `proxy` 标签）；无法识别代理出口时不显示猜测的 IP。

## 资源与路由

资源页显示文件大小、更新时间、Geo 来源和更新/删除操作，工具栏可导入文件、更新全部 Geo 数据库。导入及下载先写入临时文件，验证后替换已有文件；更新两份数据库时会先下载验证两份再替换。

- Geo 数据库仍使用兼容 sing-box 的 `geoip.db` / `geosite.db`，由兼容层转换为内核规则。v2rayNG 的 `.dat` 文件不能直接替代。
- 可导入 sing-box `.srs` 或源格式 `.json` 规则集，在路由规则的域名或 IP 栏填写 `rule-set:文件名`，例如 `rule-set:geoip-cn.srs`。
- 路由页顶部设置目标域名解析策略；每条规则显示匹配条件、`proxy` / `direct` / `block` 与开关。点击规则或铅笔编辑，长按拖动排序、左滑删除。
- 节点菜单包含服务重启、当前分组删除/导出、定位选中节点、去重、删除测试失败节点、延迟测试与排序、订阅更新。去重比较完整连接参数，保留同一地址端口但密码或协议版本不同的节点。

## 与 v2rayNG 设置的对应关系

| v2rayNG 设置 | ArcaenBox 对应项 |
| --- | --- |
| IPv6 / 优先 IPv6 | VPN 中的 IPv6 模式，DNS 的解析策略 |
| 本地 DNS / FakeDNS | DNS 分类中的远程 DNS、直连 DNS、DNS 分流、FakeDNS |
| Hev TUN | sing-box 的 system / gVisor / mixed 栈及 MTU |
| Sniffing / routeOnly | 流量探测：关闭、仅用于路由、覆盖目标地址 |
| 本地代理 / LAN / HTTP 代理 | 代理端口、允许局域网访问、追加系统 HTTP 代理 |
| UDP 超时 | UDP 会话超时（0 使用内核默认 300 秒） |
| Fragment | TCP TLS 出口的 TLS 记录分片或 TCP 分片及回退等待时间 |
| Mux | sing-box h2mux / smux / yamux、最大并发流数与填充 |
| 真连接测试 | 测试 URL 与并发数 |
| 当前连接 IP | 出口 IP 查询地址与底部显示开关 |
| 系统 VPN / 开机连接 | 系统 VPN 设置入口、开机自动连接 |

Xray 的 XUDP、Hev 专用参数、least-load Observatory 和 root iptables 模式没有直接套用为 sing-box 开关。TLS 分片只应用到内置 TCP TLS 出口，QUIC 和独立内核不受该选项影响。多路复用需服务端兼容，独立的节点配置优先于全局默认设置。

## 独立内核

内核管理列出 sing-box、Trojan-Go、NaïveProxy、Mieru 和 Snell。每项均有正式版/测试版选择、检查、下载、应用与恢复内置版本。切换独立内核前会停止连接，之后手动连接即可。

Snell 正式渠道内置 Mihomo 的 v4/v5 客户端，测试渠道内置 sing-snell 的 v4/v5/v6 客户端。使用 v6 时选择 Snell 测试渠道，并在节点中选择 v6 与对应的服务端模式。v6 的 `unsafe-raw` 不提供流量加密。

更新包必须为 ArcaenBox 签名且匹配 Android 架构与接口。没有发布 Android 兼容测试包的组件会提示该渠道暂不可用，不会把 Linux 或桌面二进制当成 Android 内核安装。组件更新独立于应用版本；维护者可通过 Native Components 工作流打包固定来源的新版本，经运行验证后发布签名更新。
