# ArcaenBox 1.6.3 未连接界面

未连接时只保留右下角的 A 连接按钮，隐藏状态文字、零流量数字和底栏背景。连接成功后显示真连接延迟、代理出口 IP 和流量；断开后恢复简洁界面。连接及停止期间由按钮动画显示状态。

BottomAppBar 继续作为按钮的布局锚点处理导航区安全边距，隐藏的内容不参与无障碍焦点和点击；连接时恢复原有背景、阴影及信息区。保留 1.6.2 的导航区适配，以及其他页面是否显示底栏的设置。

版本为 `1.6.3-arcaenbox.1`，versionCode `275`。构建源码为 `d4c6ef93bdcd657b5b460242577139c3bfc3911e`，对应[签名构建 34685739822](https://github.com/Gavin-LHX/ArcaenBox/actions/runs/34685739822)。

- 四个 ABI 的包名、应用名称、版本、SHA-256 和签名均已在本地复核。签名证书 SHA-256 延续 `8750ecddc7b8ce59ff13a701ed30bb5e4f5bcefef8abfd054d91b10e75822ff2`。
